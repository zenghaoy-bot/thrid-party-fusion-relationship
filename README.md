# thrid-party-fusion-relationship
A project for fusing third-party entity relationships, built with Python.

🚀 Setup
---------------------------------
# Create virtual environment
---------------------------------
python -m venv venv

# Activate venv (Windows PowerShell / CMD)
venv\Scripts\activate

# Activate venv (Mac / Linux)
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt


----------------------------
# Data cleaning
----------------------------
python extractor.py


----------------------------
# Fusion relastionship
----------------------------
python app.py
